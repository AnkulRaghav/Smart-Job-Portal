💼 Smart Job Portal

📌 Project Overview
Smart Job Portal is a web-based application developed using Django. It helps job seekers find suitable job opportunities and recruiters manage job postings and applications through an online platform.

🎯 Objectives

- Provide an online platform for job seekers.
- Allow users to search and apply for jobs.
- Enable recruiters to post and manage job vacancies.
- Manage job applications efficiently.
- Provide a user-friendly interface.

🚀 Features

- User Registration and Login
- Job Search and Job Listings
- Job Application System
- Recruiter Dashboard
- Job Posting and Management
- Applicant Management
- Analytics Dashboard
- Admin Panel

⚙️ Installation and Setup

1. Clone the Repository

git clone https://github.com/AnkulRaghav/Smart-Job-Portal.git

2. Navigate to the Project Directory

cd Smart-Job-Portal

3. Install Dependencies

pip install -r requirements.txt

4. Run Database Migrations

python manage.py migrate

5. Start the Development Server

python manage.py runserver

6. Open in Browser

http://127.0.0.1:8000/
